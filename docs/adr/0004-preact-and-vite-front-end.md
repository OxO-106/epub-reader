# Use Preact and Vite for the front end

The browser app is a Vite-built single-page app written in Preact with TypeScript, not Svelte. The Reader module wraps a vendored foliate-js, which manipulates the DOM itself, so the framework only has to host the Library screen, the table of contents and the settings controls; Preact's tiny runtime and plain-TypeScript components fit that and keep the build free of a compiler step beyond Vite's. The server is the only backend: in production it serves the built files from `dist/web`, and in development Vite proxies `/api` to it. The cost is a smaller ecosystem than React and the need to import from `preact/hooks` rather than a React-compatible package; moving to another framework later means rewriting the two screens' components but not the API client or the Reader module.
