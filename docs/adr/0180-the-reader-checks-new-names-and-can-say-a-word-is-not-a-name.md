# The reader checks new names, and can say a word is not a name

Extends ADR 0170. The name detector guesses: a capitalised word in the middle of a sentence is a name, one at the start of a sentence is a name only when something else says so, and since issue #43 a word at the start of a sentence right before a name is taken as part of it ("River Cartwright looked up." is River Cartwright, not Cartwright and a river, 卡特怀特河). That last rule is right for first names and wrong for "Later Cartwright left." when *Later* is not on the stop-list; the stop-list keeps the common cases out, but a guess remains a guess, and the model's form for a name can be wrong too.

So the reader is asked. When translation adds names to a Book's Glossary, the translate stream says so (`{"names": [{key, name, form}]}` before the text), and the Reader shows a small card that does not block reading: the name, its Chinese form in an editable field, **Keep** (saved as the reader's form; the text on screen is translated again if it changed), **Not a name** (saved; translated again), **Later** (the name keeps the model's form and stays marked "not checked" in the Glossary panel, where it can be kept or changed at any time). **Stop asking** turns the card off on this device; the Glossary panel turns it back on.

"Not a name" is a Glossary entry too (`not_name`, with no form): the detector leaves that word out of the names for this Book, and a name it made by joining a sentence-initial word ("Later Cartwright") is shortened to the name after it (Cartwright). The reader removes such an entry in the Glossary panel to undo it. Like the rest of the Glossary it holds words from the Book, never text, and goes with the Book.
