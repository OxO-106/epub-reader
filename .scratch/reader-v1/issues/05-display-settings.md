# 05: Display settings

**What to build:** In the Reader I can change font family, font size, line spacing and margins, choose light, dark or sepia, and switch between scrolling and paginated reading. The settings are remembered on this device and apply to every Book. They are not part of the Reading position, and changing them never loses my place.

**Blocked by:** 03 Read an EPUB

**Status:** ready-for-agent

- [ ] Each control changes the display immediately
- [ ] Settings persist across reloads and apply to a different Book
- [ ] Changing font size, spacing and the scroll/paginated mode keeps the reader at the same place in the Book
- [ ] Dark and sepia are legible, including the table of contents and the surrounding screen
- [ ] Playwright journey: change font size, close, reopen, same Reading position
